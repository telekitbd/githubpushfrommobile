১. প্রজেক্ট ZIP বাছুন

China Midnight Floating GitHub Build Project ZIP নির্বাচন করুন। ওয়েবসাইটটি ZIP-এর ভেতরের ফাইল বের করে GitHub-এ আপলোডের জন্য প্রস্তুত করবে।

Token শুধু এই ব্রাউজারের JavaScript থেকে GitHub API-তে পাঠানো হবে; কোনো সার্ভারে পাঠানো হয় না। তবু নিরাপত্তার জন্য Fine-grained token-এ শুধু নির্দিষ্ট repository-র Contents: Read and write permission দিন। কাজ শেষে token revoke করুন।

প্রস্তুত। ZIP, token, username ও repository পূরণ করুন।

২. সহজ নিয়ম

1
GitHub repository তৈরিgithub.com/new খুলে repository তৈরি করুন। Public বা Private যেকোনোটি চলবে।
2
Token তৈরিFine-grained token settings খুলে নির্দিষ্ট repo নির্বাচন করুন এবং Contents permission Read and write দিন।
3
Push শেষ হলে APK buildRepository → Actions → Build Android APK → Run workflow। Build সফল হলে run-এর Artifacts থেকে APK ZIP ডাউনলোড করুন।

সীমাবদ্ধতা: ব্রাউজারে ZIP পড়তে JSZip CDN লাগে, তাই ইন্টারনেট দরকার। ZIP-এ থাকা ফাইলগুলো GitHub Contents API দিয়ে একে একে commit হবে। অনেক ফাইল থাকলে কিছু সময় লাগতে পারে। Token এই পেজে paste করার আগে আপনি বিশ্বাস করেন এমন environment ব্যবহার করুন।
