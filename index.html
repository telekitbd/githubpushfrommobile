Repository ও Token

Token বানান

repo / Contents: write permission লাগবে

Token কীভাবে বানাবেন
  • Classic token: repo আগে থেকে টিক করা থাকবে, শুধু Generate চাপুন।
  • Fine-grained token: Repository access-এ আপনার repo বাছুন, Permissions → Contents → Read and write।
  • Token শুধু একবারই দেখা যায়, তাই কপি করে এখানে বসিয়ে নিন।

ফাইল

একটা picker-এ folder আর file একসাথে বাছা যায় না। একটা একটা করে যোগ করুন, সব জমা হবে, তারপর একবারেই push হবে। ZIP দিলে ভেতরের সব ফাইল খুলে যোগ হবে।

    .git, node_modules ও .DS_Store নিজে থেকেই বাদ যায়। ৫০ MB-এর বড় ফাইল বাদ দেওয়া হয়।
